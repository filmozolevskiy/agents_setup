# Agents Setup

Analyst-engineering toolbox for the FlightHub / JustFly Content Integration team. This file holds terms for the toolbox's own design work. Product and supplier vocabulary lives in [GLOSSARY.md](GLOSSARY.md).

## Language

**Flow diagram**:
A picture of one part of the FlightHub / JustFly flow at one level of detail, drawn in the shared visual style for non-technical readers.
_Avoid_: chart, flowchart, map

**Stale diagram**:
A flow diagram whose steps, branches, or labels no longer match how production behaves.
_Avoid_: outdated diagram, irrelevant diagram
